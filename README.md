# Faith Baptist Church Website

A high-energy Americana editorial website for Faith Baptist Church in Fostoria, Ohio. The experience uses the church's confirmed red, white, and blue direction, real supplied photography, and a clear first-visit path.

## Local development

```bash
npm ci
npm run dev
```

The development server opens at `http://localhost:3000`.

## Verification

```bash
npm test
npm run build
```

The build command copies the static public site into `dist/`. The build output is generated and is not committed.

## Content status

Confirmed church facts and proposed editorial copy are separated in `CONTENT_REPLACEMENT_CHECKLIST.md`. Review that file before publishing. No online giving provider, named pastor, recurring event calendar, social account, or livestream is presented as live without client confirmation.

The design contract is documented in `DESIGN.md`, and product content boundaries are documented in `PRODUCT.md`.
